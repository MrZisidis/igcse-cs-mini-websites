Common Examiner Watchpoints (Pearson 4CP0)

Watchpoint 1 · Model Choice Do not use the 7-layer OSI model

Pearson Edexcel 4CP0 assesses the 4-layer TCP/IP model exclusively (Application, Transport, Network, Data Link). Writing Session, Presentation, or Physical layers causes mark loss when naming the TCP/IP stack.

Watchpoint 2 · Encapsulation Name the header added at each layer

For top-band marks on transmission questions, state that Transport adds port & sequence numbers, Network adds source & destination IP addresses, and Data Link adds MAC addresses for the local hop.

Watchpoint 3 · Email Protocols (Paper 1 Q3c) Justify IMAP vs POP3 vs SMTP in context

Examiner commentary emphasises linking mechanism to scenario: IMAP keeps emails on the server (ideal for syncing multiple devices with limited storage); POP3 downloads and removes from server; SMTP sends outgoing mail.

Part 3 · 10 Minutes · Deep-Dive 2 (Q4 Focus: 44.3% Avg)

DNS resolves memorable names into 32-bit IPv4 or 128-bit IPv6 addresses

Spec 5.3.1 – 5.3.3

Routers forward packets using numerical IP addresses, not text URLs. In Pearson Paper 1 Question 2(c), students often lost marks by confusing what enters and leaves a Domain Name Server (DNS)—remember: the input is the URL or domain name, and the output is the IP address. Step 1 of 4 · Browser Input & Local Cache

User types a URL into the browser address bar

The user types a human-readable URL such as www.pearson.com. Before contacting the network, the browser checks its local DNS cache to see if it already knows the IP address.

IPv4 vs IPv6 Comparison (Spec 5.3.3)

Feature IPv4 (Internet Protocol v4) IPv6 (Internet Protocol v6)
Bit Length 32 bits (4 bytes) 128 bits (16 bytes)
Number Base & Format 4 denary octets (0–255 each), separated by dots (.) 8 hexadecimal groups (4 hex digits 0–F each), separated by colons (:)
Example Address 192.168.14.25 2001:0db8:85a3:0000:0000:8a2e:0370:7334
Total Address Space 2³² ≈ 4.3 billion addresses 2¹²⁸ ≈ 3.4 × 10³⁸ addresses
Shorthand Rules No leading zeros in octets; all 4 octets must be shown Leading zeros in a group can be dropped; one consecutive block of all-zero groups can become ::
Why IPv6 Was Needed Exhaustion: Rapid growth of smartphones, laptops, servers, and IoT devices ran out of unique 32-bit addresses. Provides virtually inexhaustible unique global addresses without relying heavily on Network Address Translation (NAT).
